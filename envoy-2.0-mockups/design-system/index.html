Every value on this page is read from the redesign's system.css. The app kit loads the same :root block through assets/tokens.css, so a change there flows to every screen. Instrument Sans throughout, ink on a cool ground, one indigo ramp for every state.

Buttons

Pill radius, weight 600, three sizes. Primary is ink and turns indigo on hover. Pressed is never shown by colour alone: the fill steps down the ramp, the button moves 1px, and it gets an inset lip. These are the classes audited in redesign/07-buttons.

On dark

The business surface (--biz). Add .on-dark to the container: the ramp mirrors and focus rings switch to indigo-200, because indigo-600 only reaches 2.17:1 there.

Build checks

Taken from the system.css header and enforced by redesign/_system/check.mjs. App mockups follow the same rules.

  • Rule 1 Every interactive control is at least 24x24 (WCAG 2.5.8), hit area included.
  • Rule 2 Every interactive control has a visible hover change and a focus ring.
  • Rule 3 Every .btn resolves to the token values for its variant — no local overrides.
  • Rule 4 No colour outside the palette below may appear on a system component.
  • Rule 5 Text contrast >= 4.5:1, boundaries and focus rings >= 3:1, on every surface.
